# 第一阶段需求说明

## 1. 用户与角色

- 资产管理员：维护分类、创建和维护资产台账。
- 部门资产负责人：在数据权限范围内查看、维护本部门资产。
- 普通员工：本阶段暂不提供独立操作入口，后续通过领用/归还申请参与流程。
- 系统管理员：配置用户、部门、角色、菜单和数据权限。

## 2. 资产分类

### 功能

- 按编码、名称、状态查询分类。
- 新增根分类或子分类。
- 修改分类名称、编码、默认折旧年限、排序、状态和备注。
- 删除未被子分类及资产台账引用的分类。

### 业务规则

- 分类编码在当前租户内不可重复，只允许字母、数字、下划线和中划线。
- 分类层级不能形成循环，不能将自身设置为上级分类。
- 停用分类可保留历史数据，但不能用于新建或修改资产台账。
- 存在下级分类或关联资产时禁止删除。

## 3. 资产台账

### 功能

- 按资产编码、名称、分类、状态、部门等条件分页查询。
- 新增、查看、修改资产基础信息。
- 选择使用部门和保管人。
- 删除仍处于“库存”状态的资产。

### 业务规则

- 资产编码在当前租户内不可重复。
- 资产名称、资产编码、资产分类和状态必填。
- 资产原值不得小于零；购置日期不得晚于当天。
- 保修到期日不得早于购置日期。
- 资产状态范围：库存、使用中、维修中、调拨中、已报废。
- 非库存资产必须通过后续领用、归还、维修、调拨或报废业务改变状态，不能直接删除。
- 查询和修改受 RuoYi 数据权限约束，字段映射为 `dept_id` 和 `keeper_id`。

## 4. 权限清单

| 模块 | 权限标识 |
|---|---|
| 资产分类列表 | `asset:category:list` |
| 资产分类详情 | `asset:category:query` |
| 资产分类新增 | `asset:category:add` |
| 资产分类修改 | `asset:category:edit` |
| 资产分类删除 | `asset:category:remove` |
| 资产台账列表 | `asset:info:list` |
| 资产台账详情 | `asset:info:query` |
| 资产台账新增 | `asset:info:add` |
| 资产台账修改 | `asset:info:edit` |
| 资产台账删除 | `asset:info:remove` |

## 5. 本阶段不包含

采购申请、审批流程、验收入库、领用、归还、调拨、维修、盘点、报废和统计大屏将在后续阶段实现。本阶段不通过直接编辑台账来模拟这些业务流程。
