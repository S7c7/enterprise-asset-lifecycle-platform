# 企业资产全生命周期管理平台：项目背景

## 1. 项目定位

本项目面向集团型企业、央国企及大型组织的资产管理场景，目标是把资产从需求提出到最终报废的全过程在线化、可追踪化：

```text
资产申请 → 审批 → 采购 → 验收入库 → 领用 → 调拨 → 归还 → 维修 → 报废
```

第一阶段先建立后续流程共同依赖的两项主数据能力：资产分类和资产台账。后续阶段将在此基础上逐步加入采购、库存、审批和统计分析，而不是仅修改界面名称或颜色。

## 2. 开源来源与二次开发边界

本项目后端基于 Dromara 社区的 **RuoYi-Vue-Plus** 5.X 分支二次开发，前端基于 **plus-ui** 5.X 分支二次开发。认证、租户、RBAC、数据权限、日志、MyBatis-Plus、Redis 等通用能力来自原开源框架；资产领域的数据模型、业务规则、接口和页面由本项目新增。

- 后端上游：https://github.com/dromara/RuoYi-Vue-Plus
- 前端上游：https://github.com/JavaLionLi/plus-ui
- 原项目许可证：MIT
- 仓库根目录的 `LICENSE` 必须保留，不得删除或改写原作者版权声明。

对外介绍建议使用准确表述：

> 基于 RuoYi-Vue-Plus 企业级后台框架进行二次开发，独立完成资产管理领域的需求分析、数据建模、核心业务模块、权限设计、测试及部署。

## 3. 第一阶段交付目标

1. 建立独立 `ruoyi-asset` 业务模块，隔离框架代码与资产领域代码。
2. 建立 `asset_category`、`asset_info` 两张核心表。
3. 实现资产分类、资产台账基础 CRUD、校验和数据权限。
4. 接入现有菜单和按钮权限体系。
5. 提供可直接操作的 Vue 页面。
6. 建立持续维护的项目文档。
